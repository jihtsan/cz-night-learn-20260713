# PPT 与 Skill：从长文到可交付 PPT 的四步提示词

本讲义配套课件：[[AI办公课/07-常州夜校003-PPT与Skill-从长文到可交付PPT|常州夜校 003：PPT 与 Skill]]。

> [!important] 先记住
> AI 生成 PPT 不是把一篇文章直接“变成幻灯片”。更可靠的路径是：**先确定故事，再定义每页，再准备素材，最后生成并检查。**

```mermaid
flowchart LR
    A[原始材料] --> B[1. 提炼内容与故事线]
    B --> C[2. 锁定页面规格与视觉风格]
    C --> D[3. 生成素材与图片]
    D --> E[4. 生成 PPT]
    E --> F[人工检查与迭代]
```

## 使用前：准备 5 项信息

在任何一步开始前，尽量先补齐：

1. **受众**：谁来看？例如部门负责人、客户、课堂学员。
2. **目标**：希望对方理解、决定或行动什么？
3. **材料**：原文、数据表、已有图表、品牌规范、模板。
4. **篇幅**：需要几页、讲多久。
5. **约束**：哪些事实不能猜、哪些数据必须保留、是否必须使用现有模板。

## 第一步：从原始材料提炼内容与故事线

### 这一阶段要拿到什么

- 汇报的一句话中心结论；
- 受众最需要知道的 3～5 个观点；
- 一条逐页推进的故事线；
- 尚缺的数据和待确认问题。

### AI 对话提示词 1｜先做内容，而不是直接做 PPT

```markdown
你是一名汇报策划师。请根据我提供的原始材料，为【受众】设计一份
【5】页、用于【时长】分钟汇报的 PPT 内容方案。

本次汇报要推动的结果是：【希望受众理解、决定或行动什么】。

请先不要生成 PPT，也不要设计版式。严格按以下步骤工作：

1. 用 1 句话写出整份 PPT 的中心结论；
2. 从材料中筛选出最能支撑结论的 3～5 个观点；
3. 设计一个逐页推进的故事线：每页回答一个问题，后一页要承接前一页；
4. 对每页输出：页码、结论式标题、核心观点、可使用的原文证据或数据；
5. 单列“待确认信息”：没有证据的内容必须标记为“待确认”，不得自行编造。

材料中的数字、机构名称和因果关系必须可追溯。请先输出 Markdown 方案，
等待我确认后再进入下一步。
```

### 本课案例的正确故事线

原文《不会用 AI 的人，正在被谁淘汰》可以被压缩为 5 页：

| 页码 | 结论式标题 | 本页回答的问题 |
|---|---|---|
| 1 | AI 首先重写的是任务，不是瞬间消失的岗位 | 变化到底是什么？ |
| 2 | 最先承压的是重复、可数字化、低判断密度的任务 | 哪些工作先变化？ |
| 3 | 入门岗位被“拆薄”，职业入口的门槛正在抬高 | 为什么年轻人与初级岗位更要关注？ |
| 4 | 人的价值转向判断、责任、沟通与协作 | 什么不会被简单替代？ |
| 5 | 把 AI 接入主任务链，才能把自己升级为结果交付者 | 个人下一步如何行动？ |

## 第二步：让 AI 提出视觉方向，再锁定每页表达方式

### 这一阶段要拿到什么

这一步不要一开始就指定“苹果风”“科技风”之类的名词。先让 AI 根据材料、受众和汇报目标提出 **3 条有理由的视觉方向**，再由人选择其中一条，并先做一张首页预览。

选定方向后，每页都要有一份“页面规格（Slide Spec）”。它不是完整设计稿，但要写清：

- 这一页唯一要传达的观点；
- 用什么证据；
- 用文字、图表、流程、对比还是图片表达；
- 页面结构与视觉风格；
- 哪些内容需要生成素材。

### AI 对话提示词 2｜先探索视觉方向，再产出页面规格

```markdown
你是一名演示文稿创意总监。根据我提供的材料、受众、汇报目标和已确认的故事线，
先不要生成整份 PPT，也不要假定我已经选定视觉风格。

请提出 3 条彼此明显不同、且确实适合本次内容的视觉方向。每条都要包括：
1. 方向名称（用易懂的描述，不要只给风格标签）；
2. 为什么适合这份材料与受众；
3. 页面语言：留白、信息密度、字体感觉、配色、图表和图片的使用方式；
4. 封面构图建议；
5. 适用风险：可能显得太严肃、太抽象或不适合哪些内容；
6. 可直接生成“仅首页预览”的中文生图提示词。

然后推荐其中 1 条，并解释推荐理由。停止，等待我选定方向。

我选定方向后，再为每页输出页面规格：
1. 结论式标题（不超过 22 个字）；
2. 本页唯一核心观点；
3. 证据：可使用的数据、原话或案例；
4. 表达形式：大数字 / 对比 / 流程 / 图表 / 图片 / 清单之一；
5. 页面结构：例如“左侧文字、右侧图表”；
6. 视觉重点：颜色、留白、强调元素；
7. 是否需要图片；如需要，说明图片承担的信息作用。

若材料不足以支持某个页面，请标记“待确认”，不要补造数据。首页预览确认后，再生成整份 PPT。
```

> [!tip] 不要跳过首页预览
> 首页是最低成本的“视觉验收样品”。如果标题空间、色彩、图片气质和信息密度都不对，应先改视觉方向，而不是生成 20 页后再推倒重来。

### 页面规格示例

```markdown
第 2 页｜最先承压的是低判断密度任务

- 核心观点：AI 优先接管录入、汇总、改写、检索、分流和初稿等任务。
- 证据：原文列举的行政、客服、初级内容与报表整合工作。
- 表达形式：六项任务的横向对比。
- 页面结构：上方结论标题；中部六项任务；底部一句解释。
- 视觉重点：白底、深灰字、六个蓝色强调点；保持足够留白。
- 图片：不需要，结构化信息比装饰图片更清楚。
```

## 第三步：按已选视觉方向生成素材与图片

### 先做素材计划，不要每页硬塞图片

| 页面类型 | 优先选择 | 一般不需要 |
|---|---|---|
| 数据结论页 | 图表、大数字 | 与数据无关的装饰图 |
| 流程说明页 | 流程图、步骤图 | 复杂人物插画 |
| 抽象概念页 | 概念图、AI 生图 | 密集文字 |
| 封面或转场页 | 氛围图、主题图 | 多个小素材拼贴 |

### AI 对话提示词 3｜输出素材表与生图提示词

```markdown
你是一名演示文稿视觉总监。根据下面**已被我确认的视觉方向**和逐页页面规格，
为 PPT 制作一份素材计划。

请逐页判断：这页是否真的需要图片。数据页、流程页和清单页如果
用图表或结构化表达更清楚，就不要建议装饰图片。

对需要 AI 生图的页面，输出一张 Markdown 表格，包含：
- 页码与页面标题；
- 图片承担的作用；
- 推荐画面；
- 可直接用于生图工具的中文提示词；
- 画幅与构图要求；
- 避免项。

必须延续已选视觉方向，不要擅自换成“通用科技风”。图片必须为标题和结论
留出文字空间；不出现文字、品牌 Logo、界面截图或水印。
```

### 本课案例的两条生图提示词

**封面图：**

```text
高端编辑风格的概念图：左侧是一叠长文档，右侧是一组清晰有序的
演示文稿页面，两者由一条明亮蓝色光线连接，表达“长文到 PPT 故事线”。
深黑背景，精致 3D 纸张雕塑质感，16:9 宽画幅；
左侧保留大面积深色留白用于白色标题。不要文字、字母、数字、Logo、
界面截图、水印或人物。
```

**人工检查页：**

```text
极简高端静物摄影：一只手拿着红色铅笔，正在检查一组空白白色演示页面，
旁边有一个蓝色几何对勾，表达“AI 生成后仍由人负责检查”。
浅灰背景、柔和日光、16:9 宽画幅；
物体集中在右下方，左侧留出大面积空白用于文字。不要可读文字、数字、
Logo、界面截图、水印或可识别的人脸。
```

## 第四步：生成 PPT 文件

### AI 对话提示词 4｜用内容、页面规格和素材生成 PPT

```markdown
你是一名 PowerPoint 制作专家。请根据已确认的故事线、逐页页面规格、
视觉规范和素材，生成一份【16:9】PPT。

要求：
1. 每页只表达一个核心观点，标题使用结论句；
2. 严格使用我已经确认的视觉方向及首页预览中确认的色彩、留白、字体气质和图片语言；
3. 图表、流程和文字必须以可编辑对象保留；
4. 仅在素材计划标记为“需要图片”的页面插图；
5. 不得编造原材料没有的数据、案例、机构或结论；
6. 字号要适合投屏；标题不得折成两行；
7. 生成后逐页检查：文字是否溢出、图片是否裁切错误、对齐和留白是否一致、
   图表口径是否正确、页面能否在 30～60 秒内讲清。

请先输出“将生成的页码、标题、内容形式、所用素材”的清单，
我确认后再生成 PPT 文件。
```

### 如果已有公司模板

把上面提示词中的第 2、3 条替换为：

```markdown
必须基于我提供的公司模板填充内容。保留模板的母版、字体、字号、色彩、
页眉页脚、页码和占位区；优先把内容匹配到已有版式。内容放不下时，
应缩短文案、拆分页面或换用更合适的模板页，不得随意缩小字号或重做模板。
```

## 最后一步：人类检查不能省

> [!warning] AI 生成的是初稿，人交付的是结果。

- **事实**：数据、机构、案例是否能回到原始材料？
- **逻辑**：每页是否只讲一个观点，并推动下一个问题？
- **可读性**：投屏时能否迅速看清标题和关键数字？
- **视觉**：图片是否与结论相关，是否有裁切、遮挡、文字溢出？
- **责任**：是否有不应上传的敏感信息、版权风险或不当结论？

## 一句话复盘

**Skill 的价值，不是替你“按一下就出 PPT”，而是让 AI 每次都按同一套可靠流程：先理解内容，再设计表达，最后生成并检查。**
