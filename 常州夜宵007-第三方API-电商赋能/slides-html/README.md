# 第 7 课 HTML 互动课件：第三方 API 与电商赋能

课程主题：让第五节搭建的电商系统连接地图、天气、企业通信，以及后续的支付、电商渠道和物流平台。

## 课程目标

- 区分自有 API 与第三方开放平台 API。
- 认识 API Key、SDK、Webhook 与平台权限。
- 理解地图、天气、企业通信如何进入电商交易链路。
- 完成“选择门店 → 查询天气 → 创建订单 → 通知商家”的互动演示。
- 了解支付、淘宝开放平台、顺丰与快递100的后续扩展方向。

## 建议时长（约 60 分钟）

1. 0–8 分钟：承接第五节，自有 API 与第三方 API。
2. 8–18 分钟：主流开放平台与电商能力地图。
3. 18–32 分钟：地图与天气 API。
4. 32–48 分钟：飞书/企业微信订单通知与完整链路。
5. 48–56 分钟：支付、电商渠道与物流预告。
6. 56–60 分钟：安全边界、总结与课堂练习。

## 使用

可直接双击 `index.html`，也可以启动本地静态服务器：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173/常州夜宵007-第三方API-电商赋能/slides-html/
```

## 演示控制

- `←` / `→`、`PageUp` / `PageDown`：前后翻页。
- 空格：下一页。
- `F`：全屏。
- `O`：页面目录。
- `N`：打开或关闭讲师备注。
- `R`：重播当前页动画或重置当前页互动。
- `A`：跳转资料来源附录。
- 手机、平板：左右滑动翻页。

页面中的红色“下一步”“选择门店”“模拟下单”等按钮用于课堂互动，不会发出真实网络请求。

## 交互页

- 第三方 API 的五个组成部分逐步揭示。
- 主流平台能力点选与电商场景映射。
- 模拟地图门店选择。
- 地图与天气 API 串联步骤。
- 模拟下单、数据库保存与飞书/企业微信提醒。
- 支付、电商渠道、物流平台后续能力切换。
