# 第 7 课 HTML 互动课件：第三方 API 与电商赋能

课程主题：从第五节的一笔订单出发，先用飞书或企业微信解决商家通知，再扩展地图与天气，最后认识支付、电商渠道和物流平台。

## 课程目标

- 区分自有 API 与第三方开放平台 API。
- 认识 API Key、SDK、Webhook 与平台权限。
- 理解地图、天气、企业通信如何进入电商交易链路。
- 完成“创建订单 → 通知商家”的互动演示，并理解地图、天气与订单的完整业务链路。
- 了解支付、淘宝开放平台、顺丰与快递100的后续扩展方向。

## 建议时长（约 60 分钟）

1. 0–9 分钟：承接第五节，从订单 #2048 发现“商家不知道”的问题。
2. 9–23 分钟：理解订单通知价值，接入飞书/企业微信并完成模拟提醒。
3. 23–37 分钟：从订单通知扩展到地图与天气两个用户侧能力。
4. 37–49 分钟：复盘完整链路、后台展示与可靠接入边界。
5. 49–54 分钟：支付、淘宝、顺丰、快递100的后续方向。
6. 54–60 分钟：归纳主流开放平台全景，并完成课堂收束。

## 使用

可直接双击 `index.html`，也可以启动本地静态服务器：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173/常州夜宵007-第三方API-电商赋能/slides-html/
```

## 演示控制

- `←` / `→`、`PageUp` / `PageDown`：前后翻页。
- 空格：下一页。
- `F`：全屏。
- `O`：页面目录。
- `N`：打开或关闭讲师备注。
- `R`：重播当前页动画或重置当前页互动。
- `A`：跳转资料来源附录。
- 手机、平板：左右滑动翻页。

页面中的红色“下一步”“选择门店”“模拟下单”等按钮用于课堂互动，不会发出真实网络请求。

## 交互页

- 订单通知的第三方接入层级逐步揭示。
- 订单通知完成后，再扩展地图与天气能力。
- 模拟地图门店选择。
- 地图与天气 API 串联步骤。
- 模拟下单、数据库保存与飞书/企业微信提醒。
- 三个案例完成后的主流平台能力全景。
- 支付、电商渠道、物流平台后续能力切换。
