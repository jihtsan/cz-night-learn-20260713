11 · 安全与可靠性

会调用只是开始，
可靠接入还要守住四条线

01密钥不进前端Secret、私钥和永久凭证只放后端
02失败要有退路超时、错误码、重试和日志
03回调必须验真验签、幂等、避免重复处理
04数据只取所需位置、手机号和订单信息最小化

通知失败怎么办？订单保留 → 记录失败 → 稍后重试。

建议用时 4 分钟。结合刚才的订单通知追问。密钥为什么不放浏览器？平台为什么会限流？Webhook 为什么可能重复？让学生记住：第三方平台不稳定时，自己的核心业务仍应有明确结果。 [Sources] 安全原则综合自各平台官方鉴权、密钥与回调文档；本页不展示具体算法。
