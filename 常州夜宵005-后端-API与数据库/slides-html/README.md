# 第5课 HTML 互动课件

课程主题：从网页到应用——后端 API 与数据库。

补充课程大纲：[[常州夜宵005-后端-API与数据库/01-Git与AI协作-小白课程大纲|Git 与 AI 协作：给代码一台“时光机”]]

Git 配套 HTML 课件：[[常州夜宵005-后端-API与数据库/git-slides-html/README|Git × AI 小白 HTML 幻灯片]]

课件以“AI 玄学电商管理系统”为贯穿案例，主要包含两条讲解线：

1. Web 从静态文档、动态网站、数据驱动、Ajax 走到多端 API 应用的历史演进。
2. 纯前端遇到保存、共享和信任问题后，如何引出后端、API、数据库与框架生态。

## 使用

可直接双击 `index.html`，也可以在本目录启动静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 演示控制

- `←` / `→`、`PageUp` / `PageDown`：翻页
- `F`：全屏
- `O`：页面目录
- `N`：讲师备注
- `R`：重播当前页入场动画
- `A`：跳到资料来源附录
- 手机、平板：左右滑动翻页

## 互动页

- API 打电话演示
- 前端篡改价格演示
- 新增商品端到端数据流
- 前端 / 后端 / 数据库职责判断

## 视觉素材

- 课件内置 2 张 AI 生成插画：赛博玄学商品与 Web 演进。
- 通用功能图标来自 Lucide，技术品牌图标来自 Simple Icons，所有素材均保存在本地。

## 建议时长

- 55 分钟：缩短历史案例，略过数据关系页，语言生态控制在 5 分钟。
- 65 分钟：按讲师备注的建议节奏讲解。
- 75 分钟：展开价格篡改、完整数据流和职责判断互动。
