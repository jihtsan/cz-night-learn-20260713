# Git × AI 小白 HTML 幻灯片

课程主题：Git 与 AI 协作——给代码一台“时光机”。

课件面向零基础学员，共 10 页：

1. Git × AI 封面与翻车引子；
2. Git、GitHub、本地仓库与远程仓库；
3. 工作区 → 暂存区 → Commit → Push；
4. 可点击演示 `git add → git commit` 的本地时间线；
5. Push 本地 / 远程双轨同步；
6. 可点击展开的 Branch 树状分叉；
7. 小白基础命令地图；
8. Worktree 概念；
9. AI 安全协作流程与对话；
10. 课堂挑战与复盘。

## 使用

直接双击 `index.html` 即可离线使用。如果浏览器在 `file://` 模式下限制全屏，可在本目录启动静态服务器：

```bash
python3 -m http.server 4174
```

然后访问 `http://localhost:4174`。

## 演示控制

- `←` / `→`、`PageUp` / `PageDown`：翻页
- `F`：全屏
- `O`：页面目录
- `N`：讲师备注
- `R`：重播当前页动画
- `Home` / `End`：首页 / 末页
- 手机、平板：左右滑动翻页

所有核心内容、样式和交互均保存在本地，不依赖外部 CDN。
