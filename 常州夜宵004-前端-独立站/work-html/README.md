# 拾光导航

一个具有 Apple 风格的卡片式网站导航页。

## 功能

- GitHub 近 7 天新项目趋势 Top 5，并提供本周榜单兜底数据
- 网站名称和描述实时搜索
- 按 AI、设计、开发、效率和学习分类筛选
- 带品牌 Icon 的网站卡片
- Apple Music 风格的《That Girl》互动播放器，在线获取封面、歌曲信息和官方试听音频
- `Cmd/Ctrl + K` 快速聚焦搜索
- 响应式桌面与移动端布局

## 技术栈

- React 19 + Vite 8 + TypeScript
- Tailwind CSS 4
- shadcn/ui 组件结构
- Motion for React
- Magic UI 风格 `AnimatedGridPattern`
- Radix UI + Lucide + React Icons

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```
