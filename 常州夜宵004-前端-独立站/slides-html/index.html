01 · 今天的任务

今天不是来背代码的

把你脑海中的一个页面，变成浏览器里真正可以打开的作品。

提出想法→ 描述需求→ AI 生成→ 浏览器查看→ 继续修改
AI 帮你写代码；创意、选择和验收仍然属于你。
降低学生对编程的恐惧。先展示结果，再介绍过程。提醒学生第一次生成只是起点。
02 · Web 的三种基础材料

浏览器最终只认识三样东西

HTML

房子的结构

决定页面里有什么

CSS

房子的装修

决定颜色、间距和排版

JavaScript

电器和机关

决定点击以后发生什么
只建立直觉，不介绍标签、选择器、变量或函数。用搜索框、网站卡片和深色模式举例。
03 · 三层能力

同一个页面，可以不断升级

1 只有 HTML 学习网站 有内容，但比较朴素
2 加入 CSS
✦ 学习网站
开始有颜色、层次和设计感
3 加入 JavaScript 现在可以响应你的操作
现场点击第三张卡片。说明 HTML、CSS、JavaScript 各自负责不同工作，但共同组成网页。
04 · 为什么需要框架

框架是为了管理复杂度

页面越复杂，
重复和关联就越多。

个人导航页 搜索框 分类菜单 网站卡片 × 20 设置弹窗

React、Vue 和 Angular 帮我们把复杂页面拆成可以重复使用的“乐高零件”。

简单网页不一定需要框架。框架解决的是页面复杂以后是否还能继续修改，而不是决定网页能不能做。
05 · 现代前端地图

现代前端是一套组合，不是一个工具

用户看到的产品页面与交互
组件库按钮 · 卡片 · 弹窗
前端框架React · Vue · Angular
Web 基础HTML · CSS · JavaScript
开发工具Node.js · npm · Vite

无论使用什么框架，最终都要变成浏览器能够理解的 HTML、CSS 和 JavaScript。

重点区分框架、组件库与工具链的位置。不要进入具体 API。
06 · React / Vue / Angular

没有最好的框架，只有更合适的路线

React

自由组合的 UI 积木

  • 选择多
  • 生态大
  • 适合独立产品
VVue

清楚、渐进的学习路线

  • 结构直观
  • 官方生态清楚
  • 适合中小项目
AAngular

规范完整的工程体系

  • 集成度高
  • 约束更强
  • 适合大型团队
不比较性能，不争论谁最好。React 讲自由，Vue 讲渐进，Angular 讲规范。来源：react.dev、vuejs.org、angular.dev。

12 · 统一技术路线

本课只走一条简单路线

+
Vite启动项目
+
Tailwind完成样式
+
Motion加入动画

这只是本课程选择的一条路线，不代表所有网站都必须这样做。

统一技术栈是为了减少安装和依赖问题。后续可以把同一页面部署成独立站，再改造成浏览器新标签页插件。
13 · 教师现场示范

把一句想法变成页面

第一轮：先把页面做出来
使用 React、Vite 和 Tailwind CSS 创建一个个人导航页。顶部显示标题和搜索框，下面按照学习、工作、娱乐三个分类展示网站卡片。整体使用简洁的浅色风格，暂时不使用后端。
第二轮：再增加动画和个性
保留现有结构和功能，使用 Motion 为卡片增加依次进入、悬停和点击反馈。再加入一个低强度动态背景，确保文字清楚、手机端可用。
生成→运行→观察→只改一件事
不追求第一次生成完美结果。演示如何限定修改范围，以及每次修改后回到浏览器检查。

15 · 创作方向

不知道做什么？先选择一个主题

学习导航课程 · 工具 · AI 网站
工作首页邮箱 · 文档 · 项目
设计师首页灵感 · 配色 · 字体

赛博朋克深色 · 霓虹 · 动态
治愈系柔和 · 插画 · 每日一句

没有唯一标准答案。主题越具体，AI 越容易做出有个性的页面。

这页可以在学生操作时循环展示。鼓励不同主题，不提供统一视觉模板。
16 · 提示词不是咒语

让 AI 听懂你的四个问题

  1. 01我要做什么？产品与使用者
  2. 02页面里有什么？区域与内容
  3. 03希望它长什么样？风格、颜色与布局
  4. 04用户可以做什么？点击、搜索与切换
“做一个治愈系个人导航页：米白背景、浅绿和橙色强调、圆润卡片；包含问候语、搜索框和三个分类；点击卡片在新标签页打开。”
提示词的价值是把模糊想法变得具体。进一步修改时，要求 AI 保留现有结构，只修改指定部分。
17 · 验收比生成更重要

完成第一版后，检查这六件事

01页面能打开

没有空白页和报错

02链接能使用

搜索和网站入口正确

03文字看得清

颜色和背景有足够对比

04手机端可用

没有明显错位和横向滚动

05动画不打扰

不影响阅读和点击

06完成两轮修改

作品体现你的主动选择

出现问题时交给 AI：截图 + 完整错误 + 期望效果 + 不能修改的内容

强调 Vibe Coding 的核心不是一次生成，而是描述、判断、测试和迭代。
18 · 展示与互评

作品展示：没有唯一正确答案

1

你做的是什么主题？

2

你主动要求 AI 修改了什么？

3

下一步你还想增加什么？

创意是否鲜明页面是否易用视觉是否统一哪个细节值得借鉴
不用代码是否高级评价作品。重点评价表达、选择、迭代与完成度。
