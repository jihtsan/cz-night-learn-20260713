# 第一课 HTML 幻灯片

主文件：`index.html`

## 打开方式

可以直接双击 `index.html`，也可以使用任意静态文件服务器打开本目录。

推荐课堂演示时使用 Chrome 或 Edge，并进入全屏。

## 操作方式

| 操作 | 功能 |
|---|---|
| `←` / `→` | 上一页 / 下一页 |
| 空格 / Page Down | 下一页 |
| Home / End | 封面 / 最后一页 |
| `F` | 切换全屏 |
| `O` | 打开目录 |
| `N` | 显示或隐藏讲师备注 |
| `A` | 跳到附录 |
| 手机左右滑动 | 前后翻页 |

第 15 张幻灯片包含一个 40 分钟课堂实践计时器。
