## PART-01 · 项目情况介绍(P3–P7)

### 论点 1 · 行业痛点(用一个真实场景开篇)

金融舆情的四个结构性痛点:

1. **传统舆情 = 关键词 + 规则,不懂金融语义**
   - 通用舆情工具靠关键词命中,无法区分「公司A公告利好」与「公司A被立案调查」,误报漏报严重。
   - 金融文本专业、隐晦(「收到监管函」「商誉减值」「关联交易」),通用分词和情感模型判不准。

2. **人工研判慢、主观、且贵**
   - 一条潜在负面从出现到研判,人工往往需数十分钟到数小时;声誉风险窗口可能只有分钟级。
   - 资深金融舆情分析师稀缺、人力成本高、流动性大,经验难沉淀。

3. **多源、多语言、多模态难整合**
   - 信息源:社媒、新闻、股吧、研报、公告、短视频、境外媒体;结构各异、跨语言、含图视频。
   - 同一事件跨平台碎片化,人工拼凑易遗漏关键关联。

4. **合规与审计要求严,容错率低**
   - 银行/券商/上市公司受强监管,舆情处置需留痕、可追溯、可解释;AI 输出必须可控、不造谣。
   - 通用大模型「幻觉」在金融场景是红线。

**开场场景(建议二选一,真实化)**:
- 银行消保舆情:某客户投诉短视频发酵 → Agent 30 秒内识别风险等级、关联历史、生成应对话术与上报路径。
- 上市公司舆情:某券商研报/公告被误读 → Agent 实时识别误读传播链,自动生成澄清材料草稿。

### 论点 2 · 解决方案:金融舆情智能体平台

一句话:**用 AI Agent 替代「监测员 + 分析师 + 合规审核」的组合,实现从「看见」到「看懂、研判、行动」。**

核心能力(对标资深分析师工作流):
- **智能监测**:7×24 全网 + 授权源采集,金融实体级精准命中。
- **语义研判**:识别事件类型、风险等级、传播态势、利益相关方。
- **自动应对**:生成研判报告、应对建议、口径草稿(人在回路确认)。
- **实时预警**:分级预警 + 触达(钉钉/企微/短信/系统对接)。
- **合规留痕**:每一次研判与处置全程可审计、可解释。

强调「企业级」三要素:**可控(幻觉抑制/HITL)、可私有化(数据不出域)、可审计(全程留痕)**。

### 论点 3 · 核心价值 / 量化收益

- **提效**:研判响应从「小时级 → 分钟/秒级」。
- **降本**:替代/倍增分析师产能,人均覆盖事件数提升数倍。
- **避险**:更早预警 → 降低声誉风险与合规事件损失。
- `[贵司提供]`:最好给 1–2 个真实客户 ROI 数据(如「某银行误报率下降 X%、响应时长缩短 Y%」)。

### 论点 4 · 为什么是现在(Timing)

- 大模型 + Agent 框架成熟,「理解 + 行动」首次工程可行。
- 监管对**声誉风险、投资者保护、ESG、数据合规**要求趋严(银行保险机构声誉风险办法、上市公司投资者关系指引等)。
- 金融机构数字化转型 + 数据治理就绪,私有化部署大模型成为可能。
- 通用舆情工具进入存量竞争,「智能化升级」窗口打开。

**PPT 版式**:P4 四点痛点 / P5 三栏(监测-研判-应对)/ P6 百分比(效率提升)/ P7 时机四要素。

## PART-02 · 产品方案分析(P8–P12)

### 论点 1 · 产品架构(画一张分层架构图)

- **数据采集层**:全网爬虫 + 授权数据源 + API 对接(社媒/新闻/股吧/公告/研报/境外媒体),多模态入库。
- **智能处理层**:金融实体识别(NER:公司/人物/产品/事件)、情感分析、事件抽取、谣言检测、跨语言。
- **金融知识图谱层**:公司-人物-事件-关联交易关系网,支撑关联研判与溯源。
- **Agent 编排层**:多 Agent 协同 —— 监测 Agent / 研判 Agent / 应对 Agent / 合规 Agent / 预警 Agent,支持任务规划与工具调用。
- **应用层**:舆情驾驶舱、研判报告、分级预警、投资者关系助手、危机指挥。
- **模型层**:金融行业大模型 + 私有化部署 + 可插拔主流模型。

### 论点 2 · 核心技术与差异化

- **金融语义理解**:金融领域微调 + 知识图谱,远超通用舆情工具的关键词命中。
- **低延迟实时引擎**:流式处理,秒级预警。
- **幻觉抑制 + 可解释**:金融场景必备,研判结论附证据链与出处。
- **多 Agent 编排**:复杂舆情自动拆解、协同处置。
- **低代码 Agent 配置**:业务人员可自定义研判规则与 Agent。

### 论点 3 · 部署形态与安全合规(To B/To G 硬门槛)

- **私有化**(银行/监管首选):全栈本地化、数据不出域。
- **混合云**:模型/敏感数据本地,弹性算力上云。
- **SaaS**:中小金融机构、上市公司快速接入。
- 合规:权限分级、操作审计、数据脱敏、信创/国产化适配、等保。

## PART-03 · 市场调查结果(P13–P17)

### 论点 1 · 市场规模 TAM/SAM/SOM(数字需核实出处)

- **TAM(总量市场)**:中国企业舆情监测与公关分析服务市场,量级参考数十亿元人民币;叠加金融科技/大模型应用市场更大。`[需用艾瑞/赛迪/IDC 最新报告核实]`
- **SAM(可服务市场)**:金融垂直 —— 银行、券商、基金、上市公司、地方金融监管的舆情与声誉风险管理支出。
- **SOM(3 年可获取)**:自下而上测算 —— 目标客户数 × 渗透率 × 客单价(建议给出客单价区间,如私有化百万级、SaaS 数十万/年)。
- 双口径对齐:自上而下(行业报告)与自下而上(客户数×客单价)交叉验证。

### 论点 2 · 目标客户与切入场景

- **首发客户**:城商行/农商行(消保舆情、品牌声誉)、券商(研报合规、声誉)、上市公司董办(投资者关系、危机公关)。
- **高价值场景**:消保投诉舆情、上市公司负面预警、声誉风险指挥、非法集资/地方金融风险监测(To G)。
- 客户画像:决策链(品牌/合规/办公室/IT)、采购周期(3–9 月)、预算来源(科技/品牌/合规)。

### 论点 3 · 竞争格局

四类对手 + 定位矩阵(横轴:通用↔金融垂直;纵轴:规则驱动↔Agent 智能):
- 传统舆情厂商(人民网舆情、清博、识微、蚁坊、美亚柏科等)—— 规则强、智能化弱。
- 通用大模型/Agent 平台 —— 通用强、金融纵深弱、私有化弱。
- 海外财经情报(Meltwater、Cision、Recorded Future)—— 海外数据强、本地合规弱。
- 金融机构自建 IT —— 定制深但成本高、迭代慢。
- **我们的位置**:金融垂直 × Agent 智能 × 私有化合规 的交叉点。

### 论点 4 · 壁垒 / 护城河

- 金融行业 know-how + 金融知识图谱 + 标注数据飞轮 + 合规资质 + 客户切换成本 + 生态集成(对接 OA/CRM/监管报送)。
