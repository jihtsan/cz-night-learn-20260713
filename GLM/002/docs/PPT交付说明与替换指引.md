## 二、两版差异与取舍

**主力版(推荐)**

- ✅ 内置**演讲者备注(notes)**:每页都有口播稿,可用 PPT「演讲者视图」直接看。

- ⚠️ 版式为程序化绘制(色块+文字),视觉简洁专业,但不带原模板的装饰图片。
- ⚠️ 无 Logo/团队照片(需你手动插入)。

**模板精修版**
- ✅ 保留原模板的**视觉设计与背景图片**,美观度高。
- ✅ 已把封面、目录、4 个章节页、4 组内容页的关键文字替换为金融舆情内容。
- ⚠️ 原模板部分页面占位框碎片化(一页 6-10 个小文本框),单框文字偏短,信息密度不如主力版。
- ⚠️ 模板是组合(group)嵌套结构,文字替换以「保留格式」方式完成;若你在 PowerPoint 里手动再编辑,注意不要打乱组合层级。

## 三、必须替换的真实信息(标 `[核实]` / `[贵司提供]`)

路演前,务必把以下占位替换为真实数据——**真实路演不可使用模拟数字/编造案例**。

| 位置 | 占位 | 替换为 |
| --- | --- | --- |
| 封面 | 汇报人 `[贵司提供]` | 真实姓名/头衔 |
| P6 量化价值 | 误报率↓60% / 响应 4h→10min / 效率×3 / 准确率92%+ | **真实 POC 验证数据** |
| P11 部署合规 | 等保 `[核实资质等级]` | 实际等保/信创/数据合规资质 |
| P14 市场规模 | 数十亿级 `[艾瑞/赛迪/IDC 核实]` | 最新权威报告数字+出处 |
| P17/P15 竞品对比星级 | ★ 数量 | 根据真实测评调整 |
| P19 商业模式 | 客单价/续费率 `[贵司预测]` | 真实或合理预测区间 |
| P22 融资 | 团队 `[贵司提供]` | 核心团队姓名/履历/照片 |

> P6 的城商行 POC 案例为**框架性设计**(种子轮用 POC 验证+转付费意向,比编造合同扛尽调)。若贵司已有真实 POC,请替换为真实数据;若尚无,建议路演前先跑一个小规模 POC 再讲。

## 四、在 PowerPoint 里手动完善(推荐操作)

**插入 Logo**
1. 打开主力版 → 「视图」→「幻灯片母版」,把 Logo 放到母版右上角,应用到全部页。
2. 或在封面单独插入大 Logo。

**插入团队照片(P22)**
- 删除 P22「核心团队:[贵司提供]」占位文字,插入团队照片+姓名/头衔卡片。

**编辑演讲者备注**
- 主力版每页已写口播稿,可「视图」→「备注」微调措辞。

**调整资金饼图(P21 主力版)**
- 双击环形图可改数字(研发50/数据18/客户15/团队12/运营5)。若调整比例,同步改右侧表格与口播。

**模板精修版手动微调**
- 若个别文字框溢出/换行异常:选中文字框,缩小字号或拖大文本框即可(组合内可直接编辑文字)。
