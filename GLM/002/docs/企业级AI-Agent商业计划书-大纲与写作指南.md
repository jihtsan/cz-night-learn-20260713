## 一、PPT 模板结构拆解(原始框架)

`商业计划书.pptx` 是「第一PPT」通用商业计划书模板,共 22 页,遵循经典的 **4 大模块**结构:

| 模块 | 章节 | 对应页码 | 页面类型 |
| --- | --- | --- | --- |
| 封面 | 商业计划书 / 202X / 汇报人 | P1 | 封面 |
| 目录 | CONTENTS 四大板块索引 | P2 | 目录 |
| **PART-01** | **项目情况介绍** | P3(章节页) + P4–P7 | 章节页 + 4 内容页 |
| **PART-02** | **产品投放分析** | P8(章节页) + P9–P12 | 章节页 + 4 内容页 |
| **PART-03** | **市场调查结果** | P13(章节页) + P14–P17 | 章节页 + 4 内容页 |
| **PART-04** | **未来发展预期** | P18(章节页) + P19–P22 | 章节页 + 4 内容页 |

模板里每模块固定 4 张内容页,常见版式为:**四点列表 / 三栏卡片 / 百分比数据图 / 编号要点**。
也就是说,模板天然要求你**每个大块用 3–4 个论点撑起来**,这正是 BP 的标准节奏。

> 模板是**通用框架**;企业级 AI Agent 是「技术+行业+2B」复合赛道,必须在通用骨架上注入**专业内容与证据**。下面给出适配后的写法。

## 二、企业级 AI Agent 商业计划书 · 推荐大纲(适配 PPT 模板)

严格对齐 PPT 的 4 大模块,但每个论点替换为 AI Agent 赛道的专业表达。可直接逐页填入 PPT。

### 封面(P1)
- 项目名称 / 一句话定位(例:「为企业打造可私有化部署的智能体中台」)
- 汇报人、公司、日期、融资轮次(可选)

### 目录(P2)
- 01 项目情况介绍 → 02 产品方案分析 → 03 市场与竞争 → 04 商业化与未来规划

---

### PART-01 · 项目情况介绍(P3–P7)—— 讲清「做什么、为谁做、为什么是现在」

> 作用:30 秒让投资人/决策者抓住项目价值。**痛点驱动,不要技术自嗨。**

建议 4 个论点:

1. **行业痛点 / 机会**
   - 企业里重复性脑力劳动多、知识沉淀差、系统割裂、RPA 只能做"死规则"。
   - 用 1 个真实客户场景开篇(例:某银行对公业务尽调,人工 3 天 → Agent 2 小时)。

2. **我们的解决方案:企业级 AI Agent**
   - 一句话定义产品(是什么)+ 关键能力(能干什么)。
   - 强调「企业级」三要素:**可控、可私有化、可审计**。

3. **核心价值 / 量化收益**
   - 降本(人力替代/倍增)、提效(流程时长缩短)、增收(新能力变现)。
   - 给 2–3 个量化指标(如:平均缩短流程 60%、人均产能提升 3 倍)。

4. **为什么是现在(Timing)**
   - 大模型成本下降 + Agent 框架成熟 + 企业数据治理就绪 + 政策推动(国产化/数字化转型)。

**PPT 版式建议**:P4 四点列表 / P5 三栏卡片(三类客户痛点)/ P6 百分比图(效率提升数据)/ P7 编号要点。

---

### PART-02 · 产品方案分析(P8–P12)—— 讲清「怎么做、凭什么你能做」

> 作用:展示技术深度与产品壁垒,证明不是"套壳"。

建议 4 个论点:

1. **产品架构**
   - 分层呈现:**应用层(行业 Agent)→ 编排层(多 Agent 协同/规划)→ 能力层(工具/记忆/RAG)→ 模型层(大模型 + 私有化)**。
   - 画出一张清晰的架构图(模板 P9/P11 可承载)。

2. **核心技术与差异化**
   - Agent 关键能力:**任务规划、工具调用、长短期记忆、多轮纠错、人在回路(HITL)**。
   - 差异化点:行业知识图谱、私有化部署、低代码 Agent 编排、幻觉抑制、可观测性。

3. **部署形态与安全合规**
   - 私有化 / 混合云 / SaaS 三档;数据不出域、权限分级、操作审计、国产信创适配。
   - 这是 To B / To G 的**硬门槛**,必须单列。

4. **产品里程碑 / Demo**
   - 已交付版本、标杆案例截图、路线图(POC → 行业版 → 平台化)。

**PPT 版式建议**:P9 架构图 / P10 技术四象限 / P11 部署形态对比 / P12 路线图时间轴。

---

### PART-03 · 市场调查结果(P13–P17)—— 讲清「市场多大、谁在竞争、凭什么是你赢」

> 作用:用数据证明天花板足够高,且你有位置。**数字要交叉验证,不要只堆一个超大数。**

建议 4 个论点:

1. **市场规模 TAM / SAM / SOM**
   - TAM:全球/中国企业 AI / 智能自动化市场。
   - SAM:目标行业(金融/政务/制造等)可服务市场。
   - SOM:3 年内现实可获取份额。
   - 自上而下(行业报告)与自下而上(目标客户数 × 客单价)双口径对齐。

2. **目标客户与切入场景**
   - 首发行业 + 高价值场景(如:金融合规审核、政务一网通办、制造知识库)。
   - 客户画像:预算方、决策链、采购周期、典型预算区间。

3. **竞争格局**
   - 四类对手:通用大模型平台、垂直 SaaS、传统 RPA/低代码、海外 Agent 厂商。
   - 用**定位矩阵图**(横轴:通用↔垂直;纵轴:轻量↔企业级)标出自己位置。

4. **壁垒 / 护城河**
   - 技术壁垒 + 行业 know-how + 数据飞轮 + 客户切换成本 + 生态(集成/插件)。

**PPT 版式建议**:P14 市场规模漏斗 / P15 竞争定位矩阵 / P16 客户场景卡 / P17 百分比/柱状对比图。

---

### PART-04 · 未来发展预期(P18–P22)—— 讲清「怎么赚钱、怎么长大、要多少钱」

> 作用:落到钱上——商业模式、财务、团队、融资。投资人最关心的"回报"在这里。

建议 4 个论点:

1. **商业模式与定价**
   - 收入结构:**订阅 SaaS + 私有化项目 + 按调用/Token 计费 + 行业解决方案**。
   - 客单价、续费率、毛利结构(算力/Token 成本占比)。

2. **财务预测与单位经济(Unit Economics)**
   - 3 年收入/成本/毛利预测;关键指标:**CAC、LTV、回本周期、毛利率**。
   - 模板 P21 的百分比图正好放收入结构/成本结构。

3. **团队与里程碑**
   - 核心团队(AI 工程 + 行业专家 + To B 销售);未来 12–24 月关键里程碑。

4. **融资计划与资金用途**
   - 本轮金额、估值(可选)、资金用途占比(研发/市场/团队/算力)、退出路径。

**PPT 版式建议**:P19 收入结构 + 商业模式卡 / P20 四栏里程碑 / P21 百分比图(成本/收入结构)/ P22 融资用途分配。

## 三、每一步「从哪几点来写」(写作要点速查)

| 模块 | 必须回答的核心问题 | 一句话自检 |
| --- | --- | --- |
| 项目介绍 | 解决谁的什么痛点?价值多大?为什么是现在? | 外行 30 秒能复述你的价值吗? |
| 产品方案 | 架构怎样?技术差异化?安全合规?产品成熟度? | 换个团队能复制吗? |
| 市场竞争 | 市场多大?客户是谁?对手是谁?凭什么是你? | 数字经得起追问吗? |
| 未来规划 | 怎么赚钱?多久盈利?团队行不行?要多少钱? | 钱投进去能换来什么里程碑? |

每个论点的写作公式:**观点 → 证据(数据/案例)→ 结论**。避免只有观点没有证据。

## 四、贯穿全程的「思维方式」(思考框架)

写 BP 不是堆信息,而是用一套思维方式把故事讲圆。建议在动笔前用以下框架自检:

1. **痛点驱动(Problem-first)**
   - 从客户痛点和 ROI 出发,而不是从"我有个大模型"出发。先讲「痛」,再讲「药」。

2. **以终为始 / ROI 视角**
   - 站在投资人/客户回报角度看:钱进、钱出、倍数、时间。所有内容服务于"这笔钱值不值"。

3. **第一性原理**
   - 拆解成本与价值的基本单位:一个 Agent 任务省多少人力?单次推理成本多少?毛利从哪来?

4. **TAM/SAM/SOM 双口径验证**
   - 既要有宏大叙事,也要有可验证的自下而上测算,两者交叉对齐才可信。

5. **护城河思维(多层壁垒)**
   - 单点技术不算壁垒。叠加「技术 + 数据飞轮 + 行业 know-how + 切换成本 + 生态」才稳。

6. **PMF(产品-市场契合)**
   - 用早期客户验证需求真伪与付费意愿,而非假设。有付费合同 > 有 Demo > 有 PPT。

7. **单位经济模型(Unit Economics)**
   - 做大一单不亏钱是前提:LTV/CAC > 3、毛利为正、回本周期清晰。

8. **阶段化思维**
   - 区分「验证期 → 扩张期 → 规模化期」,每个阶段目标、指标、烧钱节奏不同。

9. **风险识别与对冲**
   - 主动列出:模型幻觉、数据合规、巨头入场、客户教育周期,并给出对冲方案。

10. **叙事弧线(Storytelling)**
    - 黄金线:**机会 → 痛点 → 方案 → 优势 → 商业化 → 回报**。一气呵成,首尾呼应。

## 五、动笔顺序建议(高效产出)

1. **先填 PART-03(市场)** —— 市场规模和竞争格局定调,决定后面怎么讲。
2. **再填 PART-01(项目)** —— 用市场结论反推痛点与定位。
3. **接着 PART-02(产品)** —— 技术方案与差异化要扣住前面的定位。
4. **最后 PART-04(未来)** —— 商业模式、财务、融资要和前面对得上。
5. **回封面与目录** —— 全文写完再提炼一句话定位与标题。

> 原则:**结论先行、数据支撑、克制留白**。每页一个核心论点,字少图清。
