## PART-01 · 项目情况介绍

### P3 · 章节页
**①**:PART-01 / 项目情况介绍 / 一句话:**金融舆情正从"关键词时代"迈入"智能体时代"**。

### P4 · 行业痛点(四点列表)
**①**
1. **关键词舆情不懂金融语义** —— 无法区分「公告利好」与「被立案调查」,误报漏报严重。
2. **人工研判慢、稀缺、贵** —— 潜在负面响应需数十分钟到数小时,声誉窗口常只有分钟级。
3. **多源/多语言/多模态碎片化** —— 社媒、新闻、股吧、研报、公告、短视频、境外媒体难以整合关联。
4. **强监管下幻觉与留痕是红线** —— 银行/券商/上市公司要求可解释、可追溯,容错率低。

**② 口播**
> 金融舆情的核心矛盾是:信息海量且专业,但现有工具要么是"关键词+规则"不懂金融,要么是"人工"慢且贵,同时还要满足严苛的合规留痕。这就是我们的切入口。

**③ 图表**:四象限/四点卡片。

### P5 · 解决方案三栏(监测—研判—应对)
**①**
- **智能监测**:7×24 全网 + 授权源,金融实体级(公司/人物/产品/事件)精准命中。
- **语义研判**:事件类型、风险等级、传播态势、利益相关方自动识别。
- **自动应对**:研判报告 + 应对口径草稿(人在回路确认),分级预警触达。

**② 口播**
> 我们用 AI Agent 替代"监测员+分析师+合规审核"的组合,实现从"看见"到"看懂、研判、行动"的闭环。这是资深舆情分析师的完整工作流,首次被工程化。

### P6 · 量化价值(百分比/对比)
**①**(城商行 POC 验证,`[核实]`):
- 误报率较原通用工具 ↓ `[60%]`
- 潜在负面平均响应时长 `[4h → 10min]`

**② 口播**

### P7 · 为什么是现在(时机四要素)
**①**
- **技术**:大模型 + Agent 框架成熟,"理解 + 行动"首次工程可行。
- **监管**:声誉风险、消保、投资者保护、ESG、数据合规要求趋严。
- **基建**:金融机构数据治理就绪,私有化部署大模型成为可能。

## PART-02 · 产品方案分析

### P8 · 章节页
**①**:PART-02 / 产品方案分析 / 一句话:**金融行业大模型 + 多 Agent 编排 + 金融知识图谱**。

### P9 · 产品架构图(分层)
**①**(自下而上六层):
- **模型层**:金融行业大模型 + 私有化部署 + 可插拔主流模型。
- **Agent 编排层**:监测 / 研判 / 应对 / 合规 / 预警 多 Agent 协同,支持任务规划与工具调用。
- **金融知识图谱层**:公司—人物—事件—关联交易关系网,支撑关联研判与溯源。
- **智能处理层**:金融实体识别(NER)、情感分析、事件抽取、谣言检测、跨语言。
- **数据采集层**:全网爬虫 + 授权数据源 + API 对接(社媒/新闻/股吧/公告/研报/境外媒体)。
- **应用层**:舆情驾驶舱、研判报告、分级预警、投资者关系助手、危机指挥。

**② 口播**
> 这是我们的产品架构,核心是中间两层:金融知识图谱提供专业语义,多 Agent 编排实现复杂研判。上层是业务应用,下层支持私有化。

**③ 图表**:**分层架构图**(建议用图形化重绘,是本页核心)。

### P10 · 核心技术与差异化(四象限)
**①**
- **金融语义理解**:金融领域微调 + 知识图谱,远超通用工具的关键词命中。
- **秒级实时引擎**:流式处理,潜在风险分钟/秒级预警。
- **幻觉抑制 + 可解释**:研判结论附证据链与出处,满足合规审计。
- **多 Agent 协同 + 低代码**:复杂舆情自动拆解,业务人员可自定义 Agent。

**② 口播**
> 四个差异化点里,金融语义理解和可解释性是金融场景的硬门槛,也是通用大模型平台短期补不齐的能力。

### P11 · 部署形态与安全合规(三档对比)
**①**
| 部署 | 适用 | 要点 |
| --- | --- | --- |
| 私有化 | 银行/监管 | 全栈本地化、数据不出域 |
| 混合云 | 大中型机构 | 敏感数据本地、弹性算力上云 |
| SaaS | 中小机构/上市公司 | 快速接入、按需付费 |

合规:权限分级、操作审计、数据脱敏、信创/国产化适配、等保 `[核实资质等级]`。

**② 口播**
> 金融机构对数据出域高度敏感,所以我们三档部署都支持,私有化是银行和监管的首选。这也是我们的硬门槛之一。

### P12 · 产品路线图(时间轴)
**①**
- **Q1–Q2**:平台 GA + 金融知识图谱 v1 + 消保/声誉场景上线。
- **Q3–Q4**:私有化部署闭环 + 3 个标杆付费客户。
- **次年 H1**:行业版扩展(券商研报合规、上市公司投关)+ To G 地方金融风险监测。

**② 口播**
> 这是我们的产品路线。种子轮 18-24 个月内,目标是平台 GA、私有化闭环、三个标杆客户,然后启动 Pre-A。
