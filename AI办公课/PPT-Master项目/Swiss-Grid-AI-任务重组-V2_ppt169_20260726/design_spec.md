# Swiss Poster V2 — Sample Pages

## I. Project Information

| Item | Value |
| --- | --- |
| Project Name | Swiss Poster V2 |
| Canvas Format | PPT 16:9 (1280×720) |
| Page Count | 8-page teaching deck |
| Design Style | Swiss poster grid; black, off-white, one red accent |
| Target Audience | 常州夜校 AI 办公课学员 |

## II. Canvas Specification

1280×720；外边距 64；12 列网格；不使用卡片、阴影或渐变。

## III. Visual Theme

大字、精确线条、单色平面、每页只保留一个主视觉动作。红色表示“被压缩 / 风险”，蓝色仅标注页码和结构坐标。

## IV. Typography System

Arial + Microsoft YaHei；cover 96，display 160，title 64，body 32，annotation 20，footnote 16。

## V. Layout Principles

标题绝不超出安全区；段落不超过两行；用空白制造节奏。每页只保留一个题眼。

## VI. Icon Usage Specification

无图标。

## VII. Visualization Reference List

无图表；P03 采用文字场而非表格。

## VIII. Image Resource List

无图片。
